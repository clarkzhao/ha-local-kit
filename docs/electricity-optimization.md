# 用日账单做节费分析

本文是通用分析方法，不包含家庭账单、设备能耗、地址或真实测算结果。金额示例均为假设，不是本项目部署用户的数据。

## 先对齐数据口径

- 月账单按实际账单月比较；年累计先与已出账月份求和核对，不能把未出账本月算进去。
- 日数据按实际用电日汇总；标注起止日期、有效天数和缺失日，不用最近采集时间构造小时曲线。
- 谷时占比用同一日期范围内的谷时电量总和除以总电量。缺失分时数据不能补零。
- 接口的“平时”字段不等于本地电价中的独立平价时段。核对地区费率和字段含义；必要时只展示“总量减谷量”的非谷时电量。
- 工作日与周末差异只能说明相关性。总表不能确定空调、洗烘、电视或扫地机各用了多少电。

## 节电与移时分别计算

在同一阶梯费率持续适用的测算期间：

```text
减少峰电的节费 = 减少的峰时电量 × 峰时单价
峰移谷的节费   = 移动的电量 ×（峰时单价 − 谷时单价）
```

两种措施必须针对不同电量，不能重复计算；移时还需假设总耗电没有增加。它不会减少年度累计电量，也不会让已经跨过的阶梯退档。不要用全年平均单价代替当前边际电价。

上海普通一户一表居民第三档示例：峰时 06:00—22:00 为 0.977 元/度，谷时 22:00—次日 06:00 为 0.487 元/度。假设把 100 度峰电移到谷时，理论节费 49 元；若直接减少 100 度峰电，则为 97.70 元。跨档月有特殊加价规则，多人口优惠等也可能改变适用条件。实际按用户账单核对。

来源：[国家电网上海居民销售电价表](https://95598.cn/omg-static/omg-static/98307281230169361097301092024094.pdf)。其他地区需替换为当地现行费率，不复用上海参数。

## 用 HA 验证，而不是直接假定节能率

1. 先记录空调模式、设定温度和运行时长，再比较天气、在家情况接近的日期。运行时长本身不是耗电量。
2. 对可延后的洗烘任务尝试谷时预约，记录实际每周期耗电与次数，兼顾噪声、作息和设备说明。
3. 一次改变少量条件；报告测算假设、观察范围和结果，不把天气转凉造成的下降都算作自动化收益。
4. 没有分设备计量时，将大功率、长运行时段设备列为排查对象，而不是直接认定耗电排名。
5. 采集过期时停止生成“当前节费”结论；展示原始数据截止日和失败状态。

分析与自动控制分离。生成建议不会自动关闭家电、修改空调设定或安排清扫任务。真实账单、家庭分析图、户型和实体绑定保留在仓库外；贡献测试时从零构造合成数据，不只删除用户名。
