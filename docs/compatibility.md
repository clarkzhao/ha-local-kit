# 兼容性证据

这份记录区分“代码/模拟测试”和“先前单一私有部署中的硬件观察”。公开示例不是硬件验收结果。

- **HA**：方案从 HA Container 2026.9.1、macOS/Colima 部署抽取。房间/电费使用 native Sections，3D 使用自定义卡片；未宣称所有旧版 HA 都兼容。
- **国网**：上海、单个已绑定户号、人工登录 Chrome；日用电与月度账单成功读取，有头与导出会话的无界面采集均有真实成功证据。`--prefer-browser` 通过实际系统调度任务复用登录浏览器验证；持久 profile 后备模式尚未以真实账号单独验证。会话初始化 JavaScript 用合成数据回归，导航时不覆盖刷新值。没有承诺会话长期免验证、其他省份或多户号支持。没有实时功率/小时电量，也没有 Energy 历史统计回填。
- **LifeSmart VRF / 大金**：基于 MapleEve `502e5ac2f5c0f33a3d4b4e92b0d3ea735d32af7e`。补丁处理字符串风速、温度字段回退、O/P1 电源通道和聚合状态推送。此前在一个 V_AIR_P 实例上验证风速、目标温度及状态回报；没有完整覆盖所有模式或固件。
- **LifeSmart 灯带 / 状态同步**：同一基线的 `SL_LI_WW` 补丁采用 P1/P2 单通道命令、设备上报确认和 P2 色温方向修正；TCP 快照补丁处理重连、GetConfig 响应及定期真实查询。一个 `SL_LI_WW_V4` 私有实例有调光调色、网关读回及只读重连证据；没有验证全部灯具或固件，2700–6500 K 是集成映射范围。HA 2026.9.1 下通过 27 项灯带、状态同步及 VRF 隔离回归；公开工具不包含账号、设备 ID 或宿主机专用安装器。
- **云鲸逍遥 001**：此前固件 `v01.08.10.05` 上验证账号身份读取、机器人状态、电量、基站状态与地图读取。完整清扫/回充/洗烘动作未逐项验收；设置可用性还受设备任务状态限制。地图与 Device ID 不公开。
- **LG webOS**：配对与电视状态、输入源、音量读取有先前实机证据；完整动作矩阵与 Wake-on-LAN 未验收。使用 HA 原生集成，无 LG 驱动补丁。
- **3D**：公开虚构场景在 Node 中构建、浏览器桌面/窄屏渲染验证；可选 Blender 出口未纳入 CI。真实住宅几何没有随仓库公开。

新增云鲸身份／诊断工具有独立客户端合成测试、身份不匹配／超时／异常脱敏测试；在不安装 HA 的隔离环境执行了上游真实读取方法的 mock 传输回归，未发送机器人动作。CI 固定上游提交运行同一客户端回归。LifeSmart 启动补丁已在固定基线副本和 HA 2026.9.1 依赖环境通过 Hub 方法／取消行为测试，TCP 全部 mock；没有为测试重启或改动生产集成。
